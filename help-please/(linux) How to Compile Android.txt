		sudo apt-get install haxe -y

6. then install VLC Libaries (because we use hxvlc only)
=======================
	(UBUNTU & DEBIAN)
		sudo apt update
		sudo apt install vlc
=================
	(FEDORA)
		sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm

=================
	(UNIVERSAL SNAP)
		sudo snap install vlc
=================

7 (NORMAL WAY). Since we are compiling for Android, We need to have Android Studio
So to install it, it's either download from the web "https://developer.android.com/studio"
and insert this command "sudo tar -xvzf android-studio-*-linux.tar.gz -C /opt/" after that
type "cd /opt/android-studio/bin" and then "./studio.sh" (if it doesn't work then "chmod +x studio.sh)

7 (UNIVERSAL SNAP). Type "sudo snap install android-studio --classic" in terminal and open it from applications menu.
(for more infomation, try researching it.)

8. Set up SDK & NDK, by going under Languages & Frameworks and then Android SDK
and now check the boxes that says "Android 15.0" and "Android 8.0". Once Done, then go to SDK Tools and make sure
"Show Package Details" is checked and then checked the Build Tools "35.0.0" and "28.0.0", and don't close the SDK tools yet
because you need to check NDK and under package details, check "27.13750724"

9. install Java JDK (API 17)
=======================
	(UBUNTU & DEBIAN)
		sudo apt update
		sudo apt install openjdk-17-jdk
=================
	(FEDORA)
		sudo dnf install java-17-openjdk-devel
=================
	(ARCH LINUX)
		sudo pacman -S jdk17-openjdk
=================

10. Open Terminal and type "lime setup android" and type the directory
for Haxe (note: it use ubuntu's so it might be different inside the Linux Distro you use.
So try to research for more information, but Ubuntu can copy this, just replace the "user" with yours)
SDK: /home/user/Android/Sdk/
NDK: /home/user/Android/ndk/27.3.13750724/
JDK: /usr/lib/jvm/java-17-openjdk/java-17-openjdk-amd64/

10.5. I hope you have a Google Account because you need to go to "https://firebase.google.com/products/crashlytics"
because it needs "google-services.json" and if it's asking for "package_name" please type "com.mikolka9144.pslice"
and once it's done, put it inside of the setup folder (for instructions how to do it: https://www.youtube.com/watch?v=w1EPb-Jl1_U)

11. After all that, type "lime build android"
And then your done!
(the Android file is inisde of "export/release/android/bin/app/build/outputs/apk/release/ApplicationName.apk")

BUT WAIT! If your Linux Distro you use is not there then try researching for it.
