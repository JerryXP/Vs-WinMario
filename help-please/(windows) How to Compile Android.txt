https://git-scm.com/install/windows

https://code.visualstudio.com

5. We need to have Android Studio so download from there
"https://developer.android.com/studio"

6. Set up SDK & NDK, by going under Languages & Frameworks and then Android SDK
and now check the boxes that says "Android 15.0" and "Android 8.0". Once Done, then go to SDK Tools and make sure
"Show Package Details" is checked and then checked the Build Tools "35.0.0" and "28.0.0", and don't close the SDK tools yet
because you need to check NDK and under package details, check "27.13750724"

7. Install Java JDK 21 from anywhere.

8. Open Terminal and type "lime setup android" and type the directory for Haxe


8.5. I hope you have a Google Account because you need to go to "https://firebase.google.com/products/crashlytics"
because it needs "google-services.json" and if it's asking for "package_name" please type "com.mikolka9144.pslice"
and once it's done, put it inside of the setup folder (for instructions how to do it: https://www.youtube.com/watch?v=w1EPb-Jl1_U)

9. After all that, type "lime build android"
(the Android file is inisde of "export/release/android/bin/app/build/outputs/apk/release/ApplicationName.apk")

And then your done!
