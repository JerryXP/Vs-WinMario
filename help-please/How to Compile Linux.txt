(LINUX ONLY)

1. Download haxe 4.3.6 by inserting these inside terminal
Go to "https://haxe.org/download/linux/" for more infomation
=======================
	(UBUNTU)
		sudo add-apt-repository ppa:haxe/releases -y
		sudo apt-get update
		sudo apt-get install haxe -y
		mkdir ~/haxelib && haxelib setup ~/haxelib
=================
	(DEBIAN)
		sudo apt-get install haxe -y
		mkdir ~/haxelib && haxelib setup ~/haxelib
=================
	(FEDORA)
		sudo dnf install haxe -y
		mkdir ~/haxelib && haxelib setup ~/haxelib
=================
	(openSUSE)
		sudo zypper install haxe
		mkdir ~/haxelib && haxelib setup ~/haxelib
=================
	(ARCH LINUX)
		sudo pacman -S haxe
		mkdir ~/haxelib && haxelib setup ~/haxelib
=======================

5. once done, open terminal and install G++ Libaries (so C++ stuff can work)
=======================
	(UBUNTU & DEBIAN)
		sudo apt update
		sudo apt install (build-essential or g++)
=================
	(FEDORA)
		sudo dnf install gcc-c++
=================
	(ARCH LINUX)
		sudo pacman -S base-devel
=================

6. then install VLC Libaries (because we use hxvlc only)
=======================
	(UBUNTU & DEBIAN)
		sudo apt update
		sudo apt install vlc
=================
	(FEDORA)
		sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
		sudo dnf install vlc
=================
	(ARCH LINUX)
		sudo pacman -S vlc
=================
	(UNIVERSAL SNAP)
		sudo snap install vlc
=================
